a Java console app that manages taxpayers, tax obligations, declarations, assessments, payments, penalties, refunds and clearances.

OOP: abstract classes, interfaces, inheritance, polymorphism and custom exceptions.
Storage: arrays only, with counters.
Money and dates: BigDecimal and LocalDate.
Menu: 21 options plus Exit, using 4-step forms with BACK and CANCEL.
Safe saving: a record is saved only after every check passes, so cancelling changes nothing.
